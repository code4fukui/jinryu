# jinryu

人流センサーデータを可視化するWebアプリケーションです。本プロジェクトは、PUSHオープンデータプラットフォームを活用し、リアルタイムおよび過去のセンサー情報を取得・表示します。

## デモ

- [人流データ - FTASオープンデータ](https://code4fukui.github.io/jinryu/)
- [人流データ AICAM - FTASオープンデータ](https://code4fukui.github.io/jinryu/aicam.html)

## 機能

- **インタラクティブなチャート**: センサーの設置場所ごとに、日別・時間別の集計で人流データを可視化します。
- **期間指定フィルタリング**: 任意の期間を指定して、過去の傾向を分析できます。
- **属性データ**: AICAMのデモでは、性別や年齢層ごとの人流の内訳を表示します。
- **CSVエクスポート**: 選択した期間と場所の生データをダウンロードし、オフラインで分析できます。

## 仕組み

本プロジェクトは、HTMLとJavaScriptで構築され、GitHub Pagesでホストされている静的Webアプリケーションです。
- 当日のライブデータは、MixSoda APIから直接取得されます。
- 過去のデータは、リポジトリの `/data` ディレクトリに保存されているCSVファイルから提供されます。
- 定期実行されるGitHub Actionsが毎日最新のデータをバックアップし、網羅的な過去の記録を保持します。

## 使い方

インストールは不要です。ブラウザでデモサイトのいずれかを開くだけで利用できます。

1. ドロップダウンメニューから、エリアと特定のセンサー設置場所を選択します。
2. 日付ピッカーを使用して、表示したいデータの期間を指定します。
3. 選択内容を反映して、チャートが自動的に更新されます。
4. 「CSVダウンロード」ボタンをクリックすると、現在表示されているデータをエクスポートできます。
